❓ How to Play

  • 🟢 Beginner levels — predict what a code snippet prints or does.
  • 🟡 Intermediate levels — includes Debugging, where you spot the buggy line before time runs out.
  • 🔴 Challenge levels — Speed Code (faster timer) and a multi-step Boss level.
  • Score at least half of each level correct to pass and unlock the next one.
  • ⚔️ Language Battle — translate the same program between two languages.
  • 🥊 Sandbox Arena — pass-and-play, two players race the same questions.
  • 🧠 Concept Map — tracks your accuracy per concept across every mode.
  • Progress is saved automatically in your browser.
