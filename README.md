# 🎮 Code Quest

**Code Quest** is an interactive coding challenge website where users can learn and test their programming knowledge through fun, game-like challenges.

The project is designed to make learning programming concepts more engaging by combining coding questions with a simple gaming experience.

## 🚀 Features

* 🧠 Coding and programming challenges
* 🎮 Game-like learning experience
* 📚 Questions covering programming concepts
* 🔄 Reset functionality
* 💻 Simple and responsive web interface
* 🌐 Runs directly in the browser
* ➕ More challenges can be added in future updates

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript

## 🎯 Purpose

The goal of Code Quest is to create a fun and beginner-friendly way for students and programming learners to practice their knowledge.

Instead of simply reading programming theory, users can interact with challenges and learn through practice.
